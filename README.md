# MLVERSE · The Living Lab

An interactive machine-learning course for digital analytics. Plain HTML, CSS and ES modules: no build step.

```bash
python3 -m http.server 8746   # then open http://localhost:8746
```

- `js/ml.js` – tiny ML toolkit (logistic regression, KNN, trees, OLS, K-Means, metrics)
- `js/widgets/` – the interactive experiments
- `js/data/` – lessons, datasets (synthetic) and references
- Three themes: Midnight Lab, Soft Discovery, Forest Studio

Designed & built by Yousef Odeh.
